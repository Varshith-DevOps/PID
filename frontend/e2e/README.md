# Playwright E2E Notes

## Current coverage
- Authentication and login validation
- Basic public route protection
- Admin access to employees, attendance, and leave management

## How to run
- Install dependencies: npm install
- Run the suite: npm run e2e
- Open the UI runner: npm run e2e:ui

## Suggested next scenarios
- Employee self-service leave request flow
- Manager leave approval workflow
- Payroll run launch and review steps
- Recruitment applicant creation flow
